Community Science Museum - Semester Project

This is my semester project for the Frontend development course. The goal was to design and develop a responsive, accessible and informative website for the fictional "Community Science Museum", target audience (7–15 years old).

Github Pages:
https://stigjoran.github.io/semester-project/

Figma:

The site consists of four pages.
index.html - home / introduction and special events.
exhibitions.html - overview of the different exhibition spaces.
visit.html - practical information: opening hours, location, admission and accessibility.
get-involved.html - information and support, volunteering and internship.

Built with HTML and CSS. Responsive layout using CSS Grid and Flexbox. Mobile navigation using the checkbox "hamburger" pattern (no JavaScript).

Accessibility.
Semantic landmarks.
One h1 per page.
Skip link to jump to main content.
Alt text on all images.
Color choices with good contrast between text and background.

Performance.
All images are under 200kb.
Single CSS file shared across all pages.

SEO.
Unique page titles and meta descriptions on each page.
Semantic headings and clean HTML structure.
Descriptive link texts and well-written alt attributes.

Project progress.
