Community Science Museum - Semester Project.
This is my semester project for the Frontend development course.
The goal was to design and develop a reponsive, accessible and informative website for the fictional "Community Science Museum", target audience (7-15 year old).

Github Pages: https://stigjoran.github.io/semester-project/

The site consists of four pages:
index.html     -   home / introduction and special events.
exhibitions.html    -   Overview of the different exhibition spaces.
visit.html   -   Practical information: opening hours, location, admission and accessibility.
get-involved.html   -   Information and support, volunteering and Internship.

Built with:
HTML.
CSS.
Responsive layout using CSS Grid and flexbox.
Mobile navigation using the checkbox "hamburger" pattern (no javascript).

Accessibility:
Sematic landmarks.
One <h1> per page.
Skip link to jump to main content.
Alt text on all images.
Color choices with good contrast between text and background.

Performance:
All img are under 200kb.
Single CSS file shared across all pages.

SEO:
Unique <title> and <meta name=desciption> on each page.
Semantic headings and clean HTML structure.
Descriptive link texts and image alt attributes.
